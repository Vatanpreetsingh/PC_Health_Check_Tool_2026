# PC Health Check & IT Support Automation Tool

A simple, user-friendly PC maintenance tool built in Python for everyone—from IT professionals to casual users. This tool makes routine system maintenance easy with a clear, menu-based interface, allowing both technical and non-technical users to perform essential tasks like disk cleanup, system checks, and performance monitoring with just a few clicks.

## Features
- Disk cleanup (temporary files)
- System information (OS, CPU model, RAM)
- CPU & RAM usage monitoring
- Menu-based interface for easy use

## Technologies Used
- Python
- psutil
- send2trash

## How to Run

# Method-1 (Using Python)
1. Install Python 3
2. Install dependencies:
   pip install psutil send2trash
3. Run:
   python pc_health_tool.py

# Method-2 (Without Python)
1. Open the PC_Health_Check_Tool folder.
2. Navigate to the dist folder.
3. Double-click on pc_health_tool.exe (on Windows) or pc_health_tool (on other systems).
4. A command prompt window will appear, and you can use the tool directly.


## Use Case
This tool is perfect for everyone, whether you’re an IT Support professional, a Helpdesk agent, or just a regular computer user. It helps:
Free up disk space by cleaning temporary files
Quickly check system information like CPU, RAM, and OS version
Monitor CPU and RAM usage in real-time
With a simple, easy-to-understand interface, anyone can perform routine PC maintenance tasks in just a few clicks—saving time and keeping systems running smoothly.
